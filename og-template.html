Open Graph hero image template (1200 × 630). To capture: open DevTools (F12 or Cmd+Opt+I), open the rendering menu (three-dot menu in DevTools → More tools → Rendering), or use the device toolbar to set a custom viewport at 1200 × 630. Then run document.querySelector('.og-card') and screenshot only that element (or use a full-page screenshot once the viewport matches). Save the resulting PNG to images/og-toolkit.png. Easiest path: zoom the page to fit, then right-click the card → Capture node screenshot from DevTools' element inspector.
