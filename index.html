marketplace-ops-toolkit

Practical tools for operations leaders running manual review queues.

Fraud, content moderation, customer service QA, marketplace dispatch — anywhere humans (or controllers) make decisions at operational scale. Open-source methodologies and simulators drawn from years of hands-on work in Latin American fraud and marketplace ops.

Tool #1
Agent ROI Calculator v2
Decide which manual review queues to scale, which to optimize, and which need root-cause investigation. V2 adds false positive cost (LTV impact of blocking legit orders) and portfolio mode (allocate the next marginal agent across multiple queues).
Live · V2
Tool #2
BIN Monitoring Detection
Detect BIN-level attack patterns before they hit chargeback. Combines volume velocity, new-user clustering, and CBK rate trending into a single dashboard with adjustable thresholds and a 7-day drill-down per BIN. Includes a Python reference implementation.
Live
Tool #3
Marketplace Surge Simulator (PID Control) v2
Surge pricing using PID control. V2 adds polygon-level optimization — a 3×3 city map (Airport, Downtown, Stadium, Residential, Industrial, Suburbs, etc.) showing per-zone surge state with a time scrubber across 24h. Nine independent PIDs (one per zone) vs a single city-level PID, because city-average surge hides geographic disparity.
Live · V2
Tool #4
Chargeback Dispute Investigation Template
Walk through a chargeback like a senior fraud analyst. Interactive decision tree wizard guides you from reason code to action recommendation in 4-6 questions, with the evidence package ready. Plus the 8-section SOP structure any team can adapt.
Live
Tool #5
Workforce Forecast Calculator
How many agents do you actually need? Multi-case-type forecast based on volume × complexity × productivity × shrinkage. Compares 100% in-house vs vendor-split scenarios with cost comparison. Four pre-loaded operational presets.
Live
Tool #6
Logistics Supply Forecaster
Translate a marketplace forecast into required couriers, vehicles, sorters, and dock capacity, with day-over-day backlog cascade, storage occupation tracking, origin mix decomposition, and operational levers (boost capacity, defer origin). Two personas (3PL last-mile + fulfillment warehouse), two granularities (daily + intraday hourly+zone), side-by-side operational + financial output, sensitivity at +/- 15% and +/- 30%.
Live
Tool #7
Queue Operations Command Center
Two questions every ops leader asks at standup, fused into one tool: are we behind on SLA right now (backlog health monitor with hours-to-breach, agents-needed-to-recover, recovery cost) and what should the agent pick next (queue prioritization with risk × age × value scoring, three reprioritize modes, top-5 highlight). Four operator presets for fraud, content moderation, disputes, CS escalations.
Live
Tool #12
Vendor Performance Scorecard
Rank vendors against a weighted multi-dimensional scorecard (on-time delivery, defect rate, cost variance, lead time, response time). A/B/C tier classification with sensitivity analysis on weights, action recommendations per vendor, and money-on-the-table math. Four operator presets for kit sourcing (overseas manufacturers), 3PL last-mile carriers, BPO offshore support, and balanced multi-vendor portfolios.
Live
Tool #13
Driver / Courier Performance Scorecard
Rank drivers and couriers on weighted multi-dimensional performance with tenure-based bias correction so new drivers aren't unfairly penalized by thin data. Four-tier classification (Top / Reliable / Watch / At-Risk), best-gets-first-call simulation showing which tier absorbs the next 100 orders, turnover risk surfacing, and per-driver action recommendations. Four presets for instant delivery, gig couriers, ride-hail, and 3PL last-mile.
Live
