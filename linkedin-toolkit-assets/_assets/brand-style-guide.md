# Brand Style Guide — LinkedIn Toolkit Assets

Version: 1.0
First locked run 2026-05-29-180403. Reused run 2026-05-30-124010.

## Visual identity

Hero asset = 1200×627 LinkedIn-Featured-ready PNG: sky background variant + typography overlay. The sky carries mood, the typography carries the operator promise. Inspiration: Harsh Baranwal SaaS hero aesthetic. Pale sky, generous negative space, premium editorial typography, no decorative chrome.

## Typography

Font: Inter (Google Fonts, 400–900).

| Role | Size | Weight | Letter-spacing |
|---|---|---|---|
| Tool name (kicker) | 18px | 700 | 4px UPPERCASE |
| Hero punchy line | 84px | 800 | -2px |
| Subtitle | 26px | 500 | 0 |
| CTA pill labels | 18px | 700 | 0.5px |
| Watermark | 14px | 600 | 1.5px |

Dark type (#0A0A0A / #1A1A1A) with subtle light text-shadow over pale sky. Primary CTA = dark fill / white text; secondary = glass fill / dark border.

## Per-tool color variation (standing rule)

Each tool gets its OWN color treatment within its mood family, rather than reusing one shared PNG (so heroes in the Featured section are not identical). Backgrounds must stay pale through the central typography zone for dark-text legibility.

## Coded with AI — framing rule

Pipeline/template/brand guide/audit logs are AI-assisted. The TOOLS are NOT AI: math + presets + decision frameworks. No public-facing artifact (hero, post, Featured card, follow-up) may claim a tool is AI-powered or AI-driven.

## Layout grid

Viewport 1200×627. Padding 64px top/bottom, 80px sides. Stack: kicker, punchy (max 2 lines), subtitle, flex spacer, CTA pills row. Watermark bottom-right (80px from right, 32px from bottom).
